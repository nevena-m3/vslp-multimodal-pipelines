The external files are not copied into the repository. Their names and hashes identify the reviewed versions.

The complete registry is generated by `build_acoustic_feature_registry()` in `src/vslp/acoustic/features/registry.py`. Every row records formula, unit, task scope, evidence tier, descriptive range, ALS direction, and implementation status. Algorithms live in `src/vslp/acoustic/features/plugins/`; provenance and per-file status are written by `stage.py`.

## Source ambiguities resolved

- The spreadsheet rhythm-ratio row repeats a CPP expression. The implementation follows the DOCX power-ratio definition.
- The duplicate `F3 Bandwidth` row is interpreted as F4 for the second occurrence, consistent with F1-F5 ordering.
- Spreadsheet ranges mix reference populations, disease observations, and screening thresholds. They are descriptive flags, not clinical validity limits.
- Laptop amplitude is not reported as pascals without microphone calibration.
- Chen-style compensated nasality equations were incomplete; current outputs remain labeled proxies.

Each run writes the per-file table, long status, selected registry, computation policy, scale registry, scalar-reduction audit, and canonical handoff. Registered but unavailable features remain missing with a reason, never zero. This is research software; directions and ranges are not diagnostic cutoffs.
