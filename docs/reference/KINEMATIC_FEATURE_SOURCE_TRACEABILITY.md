The full canonical registry is generated by `feature_registry_dataframe()` in `src/vslp/analysis/kinematics/features.py` and includes formulas, landmarks, normalization, aggregation, evidence, interpretation, and source.

For cleaned position `x(t)`, velocity is `dx/dt`, acceleration is `d(dx/dt)/dt`, and jerk is `d(acceleration)/dt`. Absolute value is applied only to magnitude summaries. Path is `sum(abs(x[i]-x[i-1]))`; movement ROM is `P95(x)-P05(x)`. Coordinates are dimensionless intercanthal-normalized units unless a calibrated scale is supplied; they are never mislabeled as millimetres.

Rows are recording-task evidence. Repeated visits and tasks are not independent subjects. Subject-grouped splitting and resampling remain mandatory downstream. Continuous-speech extrema are not automatically instructed repetitions, so fallback and movement-count QC remain visible.
