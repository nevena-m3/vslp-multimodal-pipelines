# VSLP Acoustic GUI v0.16 Branding Pass

This update removes generic marketing language from the Acoustic GUI and replaces it with restrained project attribution and optional institutional branding.

## GUI branding changes

- Sidebar now displays: `VSLP`, `Acoustic Pipeline GUI v0.16`, and a copyright/attribution notice.
- The stage navigation label `Silero Segmentation` was changed to `Data Segmentation`.
- The previous large top banner was removed.
- A compact top branding strip is now available for logos.

## Optional logo files

Place authorized logo files here:

```text
src/vslp/gui/assets/branding/speech_production_lab_logo.png
src/vslp/gui/assets/branding/uoft_logo.png
```

The GUI will display these automatically if present. Use only logos you are authorized to use and follow institutional brand guidelines.
