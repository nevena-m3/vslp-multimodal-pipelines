## 7 Important design ↔ implementation differences

- **F07 speech_time_s.** Code sums final reviewed patient-speech intervals via articulation_speech_sec; the matrix described detected speech-event duration. Review the naming and intended analysis domain.

- **F07 task_elapsed_duration_s.** Matrix labels the construct Total speech duration, but code returns elapsed task time; it can choose first-to-last valid aligned word minus exclusions, or reviewed elapsed time as fallback. This is a naming/contract mismatch.

- **F08 three rates.** speaking_rate_words_min = 60 × approved word count / reviewed elapsed task seconds; speaking_rate_syll_s = approved syllable count / reviewed elapsed task seconds; articulation_rate_syll_s = approved syllable count / reviewed speech seconds. The lab has not approved passage syllables/s as a production biomarker.

- **F08 counts.** Canonical Bamboo orthographic count is 97. Active Family 08 requires an approved prompt-count manifest; legacy 99 is not its authoritative numerator. A 136-syllable constant was not found in active feature, GUI or task configuration code.

- **F09 pause_pattern_components.** The calculator returns JSON component values. mixed_dispatch.py applies pd.to_numeric(errors='coerce') to all values, so this row is NaN in the combined output. This is a concrete software defect.

- **F04 repetitions.** Formant token and named-vowel summary tables omit trial_id; centroids pool tokens across repeated trials. The source's target/category intent does not settle this reporting policy.

- **F10 repetitions.** Native DDK events carry trial_id, but both public leaves aggregate to recording level. Within-sequence breaks are respected for MAD; per-trial results are not emitted.

- **F11 energy and power.** absolute_energy_fs2 is sum(x²) over digital samples, so native sample rate changes the sum for an otherwise identical continuous signal. sound_power_digital divides that sum by seconds; it is not calibrated physical sound power or proven source parity.

- **F12 reviewed span joins.** Family 11/12 concatenates reviewed speech spans. Flux is transition-sensitive and can include artificial joins. Other descriptors may also change at joins; no comparative reference check is documented.

- **Final Alignment.** F04 and F06 stages call load_final_alignment; F07 timing uses final aligned word/phone rows. Manual corrections are incorporated by the frozen Alignment loader; none calls MFA or parses TextGrid directly.
